Handwritten Tamil Letter Recognition using Few-Shot Learning

Project report · 17 November 2026

In one line: we built a model that recognises a handwritten Tamil letter from only a few example images, including letters it never saw during training. Shown 5 examples each of 5 new letters, it picks the right letter 95.6% of the time.

1. What the project does

Tamil has 247 letters, and many of them look very similar. Teaching a normal computer model to read them needs hundreds of examples of every letter, and the model has to be retrained whenever a letter is added.

We used few-shot learning instead. The model learns how to compare handwriting rather than memorising each letter. To recognise a letter it only needs a few example images, usually 1 to 5. A new letter can be added just by giving it a few examples, with no retraining.

Before training, every image is cleaned the same way: it is turned into black-and-white, the letter is cut out from the background and centred, and it is resized to a fixed size.

3. The proposed model

Model: a Prototypical Network built on MobileNetV3, a well-known image network already pretrained on millions of general photos.

How it works, in four steps:

  1. The network turns every letter image into a list of 128 numbers, like a fingerprint of its shape.
  2. For each letter, the fingerprints of its few example images are averaged. This average is the letter's prototype.
  3. A new image is given to the letter whose prototype is closest to its fingerprint.
  4. If no prototype is close enough, the model can answer "unknown".

4. How we tested it

We split the 247 letters into three groups. The model trained on 173 letters. Another 37 letters were used to choose settings. The last 37 letters were kept completely hidden until the final test. So the test checks whether the model can recognise letters it has never seen before, which is the real goal of few-shot learning.

Each test round, called an episode, gives the model a few example images of some letters and asks it to label new images of those letters. We ran 600 rounds for each setting and report the average.

How to read this: more examples per letter means better accuracy, and more letters to choose from makes the task harder. Even with a single example, the model gets about 9 out of 10 right when choosing among 5 letters.

Other checks:

  • Confidence is trustworthy. When the model says it is 80% sure, it is right about 80% of the time (calibration error 0.044, where 0 is perfect).
  • Overall quality score (macro F1, from 0 to 1) across all 37 new letters: 0.82.
  • Accuracy by letter type: consonant 85.5%, consonant-vowel 81.9%, vowel 92.8%.

Most of its advantage comes from starting with a network that was already pretrained on general images; the same network trained from zero reached only about 85%. The other methods use a smaller network, and the best of them are within about 1 point of each other. MAML was unstable on this task.

We also trained a normal classifier (not few-shot) for comparison. It only works on letters it was trained on. Even there, the few-shot ProtoNet did better: 95.3% vs 93.5% (5 letters, 5 examples), and 60.9% vs 54.4% among all 247 letters.

7. Where the model makes mistakes

Most mistakes are between letters that really do look alike. Two patterns stand out:

  • Two-part vowel signs (ொ, ோ, ௌ) have pieces on both sides of the consonant, and these letters get mixed up with each other.
  • Consonants that differ by one small stroke or loop, for example னீ and ளீ, or டி and ழ். The small dot (pulli) is hard to see in a 48-pixel image.

9. Limitations

  • Trained on a laptop. There was no GPU, so training was short. Our tests show the model would still improve with about 5 times more training, so these results are on the low side.
  • "Unknown" answers are weak. When all 247 letters are loaded, an unfamiliar letter almost always looks close to some known letter, so the model rarely says "unknown".
  • Data quality. The images are small (48 × 48), 8 letters have only 4 to 6 images, and some images are unclear.
  • Possible duplicate letters. தெள, லெள, ளெள look exactly like the "missing" letters தௌ, லௌ, ளௌ, but are typed with a different Unicode spelling (ெ + ள instead of the single sign ௌ). They are probably the same letters, and this needs to be checked.

10. Conclusion and next steps

The proposed model, a Prototypical Network on a pretrained MobileNetV3, recognises Tamil letters it has never seen with 95.6% accuracy from 5 examples (choosing among 5 letters) and 83.3% among all 37 new letters. It is fast, its confidence scores are reliable, and new letters can be added without retraining.

Next steps:

  1. Train the same model for longer, preferably on a GPU.
  2. Collect more images for the letters with very few samples, and for the ொ / ோ / ௌ letters.
  3. Check the தெள / லெள / ளெள spelling question, and collect real handwritten தௌ, லௌ, ளௌ.
  4. Improve the "unknown letter" detection.

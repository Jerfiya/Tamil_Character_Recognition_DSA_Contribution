# 🙌 Add yourself as a contributor

Did you write letters for **`tamil_handwritten_Dataset`** as a PEP DSA student? Then add your name here. Once your pull request is merged, **your GitHub profile appears in this repository's _Contributors_ list.** ⭐

It takes about 2 minutes and works entirely in the browser. You don't need to install git.

## Steps

1. **Sign in to GitHub** with your own account.
2. Open the [`contributors/`](contributors/) folder in this repository.
3. Click **Add file → Create new file**.
   GitHub asks you to **fork** the repository the first time. Click **Fork this repository**.
4. **Name the file** after your GitHub username, for example `contributors/your-username.md`.
5. **Paste this** into the file and fill it in:

   ```markdown
   # Your Full Name

   - GitHub: @your-username
   - Department: ADS / IT / CSE / AML / CSBS
   - College: SJCE / SJIT
   - Year: 2nd Year / 3rd Year
   - Contribution: wrote, scanned and labelled handwritten Tamil letters for tamil_handwritten_Dataset
   ```

6. Click **Commit changes…** and then **Propose changes**.
7. Click **Create pull request** twice.

That's it. ✅ After the maintainer merges it, you'll show up under **Contributors** on the repository's main page. GitHub can take a few hours to update that list.

## Notes

- ✉️ **Your email must be linked to your GitHub account.** GitHub counts your commit using the email on your account. Editing in the browser, as described above, handles this automatically.
- 📁 **Create a new file. Don't edit an existing one.** Everyone gets their own file, so pull requests never clash.
- 🔒 **Don't put your email address or phone number** in the file.
